ATTRIBUTION MODEL
------------------------------------------------------------------------

Authorship is declared per skill, not per repository. Each skill folder
contains an AUTHORS file listing the people who created and maintain that
specific skill. Where a skill is co-authored, all authors are listed.

  - Solo-authored skills credit their single author.
  - Co-authored skills credit all authors jointly.

The README contains a summary table, but the AUTHORS file inside each
skill folder is the authoritative record and travels with the skill if
the folder is copied or redistributed on its own.
